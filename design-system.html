Состояния и доступность

  • Фокус с клавиатуры должен оставаться заметным. Используйте Tab для проверки компонентов в UI kit.
  • Ссылки переходят на страницы, кнопки изменяют состояние интерфейса.
  • Поля имеют подписи; ошибки обозначаются текстом вместе с aria-invalid.
  • Активные вкладки сопровождаются aria-selected или aria-expanded в зависимости от компонента.
  • Анимации учитывают prefers-reduced-motion. Карусель партнёров прокручивается пользователем.
  • Контент находится в HTML. jQuery управляет только взаимодействиями.
