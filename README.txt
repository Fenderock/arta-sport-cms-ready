ARTA SPORT — СТАТИЧЕСКИЙ HTML / CSS / JQUERY БЕЗ JS-РЕНДЕРИНГА

Все страницы, карточки, списки, варианты выбора и формы записаны в HTML.
JavaScript не создаёт разметку: он переключает готовые блоки, фильтрует
карточки, обновляет значения полей, таймеры и расчёты, обрабатывает действия.
Включены все согласованные правки и последнее расположение профиля.

Распакуйте архив целиком и откройте index.html. Сборка не нужна.
Если localStorage недоступен для file://, используйте локальный HTTP-сервер.
Контент редактируется в HTML, оформление в assets/css, поведение в assets/js.
Серверная часть отсутствует. Авторизация, оплата, сохранение профиля и
загрузка документов демонстрационные; для реальной работы нужна интеграция.

Это отдельный архив. Опубликованный сайт и предыдущий архив не заменены.
