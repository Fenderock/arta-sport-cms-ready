# ARTA Sport — статический HTML/CSS/jQuery-проект

Готовый проект на основе утверждённого дизайна Diz1. Все пользовательские страницы сделаны на чистом HTML5, CSS3, jQuery и нативном JavaScript. React, Next.js, JSX, TSX, npm-зависимости и сборщик для работы CMS-версии не требуются.

## Готовые страницы

- `index.html` — главная;
- `event.html` — страница мероприятия;
- `registration.html` — регистрация и вход;
- `lk.html` — личный кабинет;
- `about.html` — о компании;
- `offers.html` — наши предложения;
- `service-event-organization.html` — первое предложение;
- `events.html` — каталог предстоящих и прошедших мероприятий;
- `contacts.html` — контакты и форма обратной связи;
- `ui-kit.html` — интерактивная витрина дизайн-системы.

## Структура

- `assets/css/site.css` — исходная дизайн-система Diz1 и компоненты главной/кабинета;
- `assets/css/internal.css` — общие компоненты внутренних страниц;
- `assets/css/ui-kit.css` — оформление витрины компонентов;
- `assets/fonts/inter/` — локальные файлы шрифта Inter для кириллицы и латиницы;
- `assets/js/site.js` — интерактив главной и личного кабинета;
- `assets/js/internal.js` — общий интерактив внутренних страниц;
- `assets/js/animations.js` — общая система ненавязчивых анимаций;
- `assets/js/jquery.min.js` — локальная копия jQuery;
- `includes/` — шаблоны head, header/navigation, footer и scripts для CMS;
- `docs/` — дизайн-система и рекомендации по интеграции.

Для просмотра откройте `index.html`. Сервер и установка зависимостей не требуются. Если браузер ограничивает локальные переходы, запустите в папке проекта `python3 -m http.server 8080` и откройте `http://localhost:8080`.

## Важные правила интеграции

1. Не копируйте стили в HTML — используйте общие `site.css` и `internal.css`.
2. Замените повторяющиеся шапку, навигацию и подвал шаблонами из `includes/`.
3. Сохраните порядок подключения JavaScript: jQuery → скрипт страницы → `animations.js`.
4. Демонстрационные формы и массивы мероприятий замените серверными данными CMS.
5. Не меняйте имена CSS-классов при переносе: на них завязаны адаптивность и интерактив.

Полный маршрут переноса находится в `docs/CMS-INTEGRATION.md`, визуальные правила — в `docs/DESIGN-SYSTEM.md`, контрольный список состава — в `docs/PROJECT-MANIFEST.md`.
