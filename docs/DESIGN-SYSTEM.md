# Дизайн-система ARTA Sport

## Принцип

Система сохраняет визуальный язык Diz1: тёмно-синий фон, фирменный оранжевый, Inter/Arial, крупные заголовки, мягкие карточки и скруглённые кнопки. Точечные изменения не должны менять общий каркас страниц.

## Основные токены

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--bg` | `#f8fafc` | основной фон |
| `--ink` | `#0f172a` | основной текст |
| `--muted` | `#64748b` | вторичный текст |
| `--line` | `#e2e8f0` | границы |
| `--orange` | `#EA5424` | фирменный акцент |
| `--card` | `#ffffff` | карточки |
| `--radius` | `18px` | базовое скругление |
| `--shadow` | `0 20px 45px rgba(15,23,42,.12)` | крупная тень |

## Типографика

- Основной стек: `Inter, Arial, sans-serif`.
- Базовый текст: 16–19 px, межстрочный интервал 1.6–1.75.
- Заголовки первого уровня: `clamp(38px, 5.2vw, 72px)`, `line-height: 1.02`.
- Заголовки секций: `clamp(32px, 4vw, 52px)`.
- Мелкие подписи не должны быть меньше 12 px.

## Сетка и отступы

- Контейнер внутренних страниц: максимум 1180 px.
- Рабочая область шапки на больших экранах: максимум 1400 px.
- Основная секция: 92 px по вертикали, на мобильных 68 px.
- Сетка карточек: 18–20 px.
- Основные переломные точки: 1400, 1060, 980, 900, 719 и 560 px.

## Компоненты

- `.site-header`, `.mobile-menu` — общая навигация.
- `.full-footer.inner-footer` — общий четырёхколоночный footer.
- `.page-kicker`, `.page-title`, `.page-lead` — заголовочная группа.
- `.ui-button` — основная кнопка; `.secondary` — вторичная.
- `.feature-card`, `.offer-card`, `.side-card` — карточки.
- `.ui-form` — единая форма.
- `.image-hero` — hero внутренней страницы с фотографией.
- `.countdown-card` — таймер мероприятия.
- `.partner-carousel`, `.partner-strip` — ручная карусель партнёров.
- `.reveal-item`, `.is-visible` — состояния общей системы появления элементов.

## Движение

- Продолжительность появления: 550 мс.
- Смещение появления: 22 px снизу вверх.
- Последовательная задержка карточек: 55 мс, максимум пять шагов.
- Увеличение изображения при наведении: `scale(1.035)`.
- Автоматическая прокрутка каруселей запрещена.
- Все эффекты отключаются при `prefers-reduced-motion: reduce`.

## Адаптивность

- На широких экранах контент не растягивается шире заданных контейнеров.
- Подвал: четыре колонки на десктопе, две на планшете, одна на телефоне.
- Шапка остаётся липкой; её элементы удерживаются в центральной рабочей зоне.
- Изображения используют `object-fit`, логотипы — `contain`, фотографии — `cover`.
- Заголовки используют `clamp()` и не должны получать фиксированную высоту.

## Правило дальнейшей работы

Новые страницы должны подключать общие `site.css`, `internal.css`, `jquery.min.js`, соответствующий скрипт страницы и `animations.js`. Не копировать стили компонентов внутрь HTML и не менять глобальный каркас ради локальной правки.
