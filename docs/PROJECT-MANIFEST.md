# Контрольный состав проекта ARTA Sport

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | главная страница |
| `event.html` | внутренняя страница мероприятия |
| `offers.html` | «Наши предложения» |
| `service-event-organization.html` | спортивно-массовые мероприятия |
| `about.html` | «О нас» |
| `registration.html` | регистрация, вход и восстановление |
| `lk.html` | личный кабинет |

## Общие шаблоны

- `includes/head.html`;
- `includes/header.html`;
- `includes/footer.html`;
- `includes/scripts.html`.

## Общие стили и сценарии

- `assets/css/site.css`;
- `assets/css/internal.css`;
- `assets/js/jquery.min.js`;
- `assets/js/site.js`;
- `assets/js/internal.js`;
- `assets/js/animations.js`.

## Ресурсы

- логотип ARTA Sport и логотипы социальных сетей;
- фотографии мероприятий, услуг, новостей и спортивных дисциплин;
- логотипы партнеров;
- иконки блоков услуги;
- PDF-документ диплома Матч ТВ;
- `robots.txt` и `sitemap.xml`.

## Результат автоматической проверки

- 7 HTML-страниц;
- все локальные `href` и `src` разрешаются в существующие файлы;
- React, Next.js, JSX и TSX в CMS-папке отсутствуют;
- внешние библиотеки, кроме локальной jQuery, не используются;
- проект открывается без npm, Node.js и сборщика.
