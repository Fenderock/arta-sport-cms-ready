# Подготовка к интеграции с CMS

## Состав чистой CMS-версии

Корнем проекта является папка с `index.html`. Для работы нужны только HTML-файлы, `assets/`, `includes/`, `docs/`, `robots.txt` и `sitemap.xml`. Файлы React, Next.js, Node.js и сборщик отсутствуют и не требуются.

## Общие шаблоны

В `includes/` лежат четыре эталонных блока:

- `head.html` — общие CSS-ресурсы;
- `header.html` — шапка, основное и мобильное меню;
- `footer.html` — подвал, контакты и социальные сети;
- `scripts.html` — общий порядок подключения JavaScript.

При интеграции вынесите их в шаблоны CMS и замените статические копии на серверные включения.

## Интерактив

Демонстрационные массивы в `assets/js/site.js` нужно заменить серверным выводом карточек мероприятий или JSON-endpoint. JS должен оставаться только для фильтрации, интерфейса, таймера, модальных окон и личного кабинета.

Не удаляйте:

- классы `.site-header`, `.mobile-menu`, `.full-footer`;
- атрибуты `data-*`, используемые фильтрами, вкладками, модальными окнами и каруселью;
- `aria-*` у меню, кнопок и диалогов;
- подключение `animations.js` после основного скрипта страницы.

## Формы

Формы помечены классом `.js-demo-form` и сейчас не отправляют данные на сервер. В CMS замените демонстрационный обработчик на endpoint, добавьте CSRF-защиту, серверную валидацию и сохранение согласия на обработку данных.

## Последовательность переноса

1. Скопировать папки `assets/`, `includes/`, `docs/` и все HTML-файлы.
2. Создать общий layout CMS и подключить `head`, `header`, `footer`, `scripts`.
3. Перенести HTML каждой страницы без изменения классов.
4. Заменить статические карточки циклами CMS.
5. Заменить формы серверными обработчиками.
6. Сформировать реальные URL, canonical, title, description и Open Graph.
7. Обновить `sitemap.xml` и `robots.txt`.
8. Проверить меню, формы, фильтры, личный кабинет, карусель и адаптивность.

## Контроль сохранности

Перед публикацией сравните список файлов с `PROJECT-MANIFEST.md`. В подготовленной версии все локальные ссылки и пути к ресурсам проверены: отсутствующих CSS, JS, изображений, документов и HTML-страниц нет.
